ButterEye

Choppy motion in your videos?
Make it smooth in mpv.

ButterEye adds the in-between frames, live while you watch or saved as a copy — on your own GPU or CPU, with your own mpv.

  • A 24 fps film on a 60 or 144 Hz screen? It plays at your display's rate, or at 60.
  • Not sure what your computer can do? A speed test picks the engine that keeps up — RIFE, mvgpu for 4K, or MVTools.
  • Want to keep it? Save a smooth copy, with audio, subtitles and chapters; HDR10 stays HDR10.

    Check them against SHA256SUMS. The minimum is buttereye and buttereye-vs-mvtools; the others add GPU smoothing.

    ButterEye for Linux

    Choose how to install it:

    AppImageany Linux · x86-64

    AppImage: one file with everything inside, mpv included; nothing to install. Make it runnable and start it:

    chmod +x ButterEye-*-x86_64.AppImage
./ButterEye-*-x86_64.AppImage

    Needs glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36 or later. Smooths with MVTools on the CPU; the GPU engines come with Fedora's packages. Experimental: tested in clean containers of Ubuntu, Debian, Fedora and Arch, not yet on many desktops. Checksums and source code.

    Fedora: RPM packages that dnf keeps up to date, with the GPU plugins. One command installs everything.

    ButterEye for Windows

    1. Install mpv (ButterEye plays your videos in it), in PowerShell or a Command Prompt:

    winget install --exact --id shinchiro.mpv

    2. Run the installer you just downloaded. It isn't code-signed yet, so Windows SmartScreen may warn: choose More info ▸ Run anyway. It installs for your account only and asks you to accept Microsoft's terms for two runtime files that come with Python.

    3. Start ButterEye from the Start menu and drop a video on it. If Microsoft's Visual C++ runtime is missing, the installer offers it and ButterEye tells you.

    Windows 10 version 1903 or newer, 64-bit. This first Windows build is experimental: it is tested on GitHub's Windows machines and under Wine, not yet on a Windows PC with a graphics card. Checksums and source code.

    ButterEye for macOS

    1. Open the disk image you just downloaded and drag ButterEye onto Applications. Everything it needs is inside, mpv included; you don't need Homebrew.

    2. Allow it once. ButterEye isn't notarised by Apple, so macOS refuses to open it until you clear the download mark. In Terminal:

    xattr -dr com.apple.quarantine /Applications/ButterEye.app

    3. Start ButterEye from Applications and drop a video on it. If anything is still marked, ButterEye's System page says so and shows the same command.

    macOS 27 or newer, Apple silicon (M1 or newer). This first macOS build is experimental: it has been measured on one Mac, not yet on others. Checksums and source code.
